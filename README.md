# Playwright Test Suite

This repository contains Playwright UI tests under `tests/` and API tests under `api-tests/`.

## Key updates made

- `playwright.config.js` converted to CommonJS for consistent project execution.
- API test files now use `require('@playwright/test')`, so the runner works without mixed module syntax.
- Added standard npm scripts for convenience:
  - `npm test`
  - `npm run test:ui`
  - `npm run test:api`
  - `npm run test:report`
  - `npm run test:debug`
- Added `.gitignore` entries for `auth.json` and `.env` to avoid committing secrets.
- Added `.env.example` for local configuration.

## Project layout

- `playwright.config.js` - Playwright configuration file.
- `global-setup.js` - Logs in once and saves auth state for browser tests.
- `tests/` - Browser automation tests.
- `api-tests/` - API-only Playwright tests.
- `auth.json` - generated auth storage state (ignored by git).
- `.env.example` - sample environment variables.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Copy environment variables:
   ```bash
   copy .env.example .env
   ```

3. Fill `.env` with your credentials and test data.

## Run tests

- Run the full suite:
  ```bash
  npm test
  ```

- Run only UI tests:
  ```bash
  npm run test:ui
  ```

- Run only API tests:
  ```bash
  npm run test:api
  ```

- Open the HTML report:
  ```bash
  npm run test:report
  ```

- Run Playwright in debug mode:
  ```bash
  npm run test:debug
  ```

## Notes

- `auth.json` is generated by `global-setup.js` and reused for browser tests.
- Keep `.env` private and do not commit it.
